# AlbericoD.github.io

First-party product site for Windows gaming apps by **Albérico Dias Barreto Filho**:

- [DeepRivals](https://albericod.github.io/deeprivals/): Marvel Rivals live overlays, hero-switch context and post-game review.
- [Roblox Backpack Tracker](https://albericod.github.io/roblox-backpack-tracker/): Backpacks, accounts, Quick Add and personal values across Roblox Experiences.
- [Economy Tool](https://albericod.github.io/economy-tool/): Counter-Strike 2 buy context, safe drops and enemy economy estimates.
- [Fortmapp](https://albericod.github.io/fortmapp/): Fortnite maps, live routes and map-based match review.

The official Overwolf Store remains the distribution channel. Download links use the official installer and preserve site attribution.

## Local development

Run `python3 -m http.server 8000` at the repository root and open `http://localhost:8000/`. This is static HTML/CSS with one optional measurement hook, hosted by GitHub Pages. No build, package installation, framework or backend is required.

See [maintenance notes](docs/README.md), [measurement](docs/measurement.md), and [image provenance](assets/screenshots/README.md).
