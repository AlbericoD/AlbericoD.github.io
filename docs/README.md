# Site maintenance

This site intentionally stays dependency-free: static HTML/CSS served by GitHub Pages, with no build step or paid domain.

- Product pages contain the descriptive copy and structured data.
- `styles.css` owns the shared visual system and per-product accent themes.
- Direct download buttons use official Overwolf installer endpoints.
- `docs/direct-download-links.md` records the installer identifiers and attribution parameters used by the site.
- `llms.txt`, `robots.txt`, and `sitemap.xml` support machine discovery and indexing.
