# Overwolf UTM reference

The direct installer links intentionally include `utm_source`, `utm_medium`, and `utm_campaign` because Overwolf supports those parameters for install-source attribution in the Developer Console.

This site uses:

- source: `albericod_github_pages`
- medium: `owned_site`
- campaign: one stable slug per app

See `direct-download-links.md` for the current installer identifiers.
