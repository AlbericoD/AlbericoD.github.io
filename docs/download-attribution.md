# Download attribution

Direct download buttons on this site use the official Overwolf installer endpoint and attach Overwolf-supported UTM parameters so installation source can be attributed in the Developer Console.

Current values:

- `utm_source=albericod_github_pages`
- `utm_medium=owned_site`
- `utm_campaign=<app_slug>`
- `Channel=website`

Campaign slugs:

- `deeprivals`
- `roblox_backpack_tracker`
- `economy_tool`
- `fortmapp`

The canonical Overwolf Store listing remains available as a secondary link on every product page.
