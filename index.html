I’m Albérico Dias Barreto Filho. I build and maintain DeepRivals, Roblox Backpack Tracker, Economy Tool and Fortmapp.

The approach is simple: give each app a clear job, put useful information close to the game, and leave the decisions with the player.

This is the place to understand the products. Overwolf remains the official place to install them and check release information.

A few useful answers.

What do I need to run these apps?

A Windows PC, Overwolf and the relevant game. These are desktop companion apps, not browser tools or mobile apps.

Where does the download come from?

Every Download for Windows link leads to the official Overwolf installer. This site does not host or replace the installer.

Where can I check releases, pricing and support?

Use the View on Overwolf link on each product page. The official listing has current release information, available pricing details and support links.

Are these made by the game publishers?

No. These are independent companion apps built by Albérico Dias Barreto Filho and distributed through Overwolf.
